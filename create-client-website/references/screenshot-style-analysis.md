# Screenshot Style Analysis

Treat screenshots as visual references, not content sources, unless the user says otherwise.

Extract:

- Page type and likely audience
- Header/navigation layout
- Grid, section rhythm, density, and whitespace
- Typography feel, scale contrast, casing, and weight
- Color palette, contrast, neutral balance, and accent usage
- Button, card, form, badge, and divider treatments
- Image placement, cropping, subject matter, and art direction
- Motion hints visible in UI states or repeated patterns
- Overall mood and anti-references

Then translate these qualities into an original design. Do not clone proprietary layouts, brands, illustrations, copy, or exact component compositions.
