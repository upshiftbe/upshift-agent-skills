# Content Model

Use this as the default Decap CMS model for client websites. Trim collections that do not apply.

## Core Collections

- Site settings: name, description, logo, social links, contact, address, SEO defaults
- Navigation: header links, footer links, CTA labels and URLs
- Pages: title, slug, SEO, hero, sections
- Services: title, slug, summary, details, icon, image, CTA
- Testimonials: quote, name, role/company, image, featured flag
- Projects or case studies: title, slug, summary, images, results, body
- Team: name, role, bio, photo, links
- Blog or news: title, slug, date, author, excerpt, image, body

## Section Types

- Hero
- Intro copy
- Feature/service grid
- Process steps
- Proof/testimonials
- Project highlights
- FAQ
- Contact CTA
- Rich text

Keep content files readable and portable. Prefer markdown for pages/posts and JSON for global settings.
