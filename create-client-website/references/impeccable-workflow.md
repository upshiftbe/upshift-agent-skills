# Impeccable Workflow

Use this public workflow concept as process guidance. Do not duplicate Impeccable's website visual design or page copy.

## Teach

Capture audience, business goal, voice, current website style, anti-references, conversion goals, and constraints.

## Shape

Define the visual direction before coding. Use current-site analysis, uploaded screenshots, or the selected questionnaire answers.

## Craft

Code toward the approved direction with semantic markup, real content, responsive behavior, CMS fields, and deployable configuration.

## Polish

Run a pre-ship pass for accessibility, performance, theming, responsive behavior, anti-patterns, copy clarity, long content, missing content, empty states, broken images, CMS edge cases, and mobile navigation.

## Maintain

Extract repeated patterns into tokens, components, and CMS structures so future pages stay consistent.
