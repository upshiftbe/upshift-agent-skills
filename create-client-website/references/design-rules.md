# Design Rules

- Build a real website as the first screen, not a landing-page explanation of the website.
- Keep the client name, offer, and primary CTA visible in the first viewport.
- Preserve real client content and facts.
- Create a meaningfully new visual design unless the user asks to keep the current style.
- Use screenshots as inspiration, not as a one-to-one source to copy.
- Avoid generic filler, invented metrics, fake testimonials, fake awards, and vague AI-sounding claims.
- Use lucide-react icons for common UI symbols.
- Use stable responsive dimensions for headers, cards, tiles, controls, and media.
- Keep text inside buttons and cards from overflowing at mobile and desktop sizes.
- Do not make the whole site a one-color theme.
- Use motion to improve orientation and polish; avoid gratuitous animation.
- Prefer reusable sections and tokens over one-off styling once patterns repeat.
